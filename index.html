Open finn.com → F12 → Network tab → reload → filter for cars → right-click the request → Copy URL → paste it here. Base URL and actor are extracted automatically.
FINN Product API host. Auto-detected on first load; change it if the service moves.
Sent as the required x-finn-actor request header (and as actor query parameter for legacy hosts). The API rejects requests without it.
Requests are routed through this proxy. Placeholders: {url} = raw target URL, {enc} = URL-encoded, {bare} = without https://. The company anycors instance expects https://anycors.b0t.at/?{url} (whole query string = target). Leave empty for direct calls.
The default automatically merges FINN's coming-soon list (currently often empty) into the available cars — merged cars get a "coming soon" badge.
The app pages through the catalog and then filters instantly in the browser.
